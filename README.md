# Programa 2 — Lector de cómics, manga y libros — **MOON**

Lector de escritorio para **Windows 11** para leer **cómics, manga y libros** con comodidad, **subrayar y anotar**, y **buscar palabras o imágenes desconocidas** sin salir de la lectura.

> Estado: **solo planeado**. No empezar hasta que el Programa 1 tenga su primera versión (ver `../NOX/docs/03-ROADMAP.md`, hitos M0–M4). Este programa **reemplaza** la idea anterior (OrbitDrop + Morrow), que queda aparcada en `docs/01-VISION.md`, sección "Ideas aparcadas".

## Qué quiere la persona usuaria
1. Leer cómics, manga y libros cómodamente.
2. Subrayar cosas y guardar notas.
3. Buscar palabras que no conoce.
4. Buscar imágenes o elementos que no conoce y saber qué son.
5. Poder meter "varias cosas más": ver `docs/04-RESEARCH.md` para lo que otros proyectos ya hacen.
